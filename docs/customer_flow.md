# Customer Flow

Based on `2_customer_flow.mmd`:

## Phase 1 - Discover
- Open App -> Location Detected
- Home / The Lane -> Outlets ordered by walking time
- Find food via Search, Feed, Scan, or Craving Filters

## Phase 2 - Order
- Select Outlet -> Full Menu + Quick Choices
- Add Items -> One-Tap + Qty
- Pickup Cart / Ticket
- **Declare ETA** -> 5 / 10 / 15 min
- Confirm Order

## Phase 3 - Pickup
- Order Placed -> Preparing
- Ready for Pickup -> Pickup Token Issued
- Customer Collects
